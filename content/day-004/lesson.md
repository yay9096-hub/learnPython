## 📌 知识卡 1 · `input()` —— 程序会问问题了

```python runnable 试着回答它
name = input("请输入你的名字：")
print(f"欢迎你，{name}！")
```

点 ▶ 之后，下面的输出区会长出一个输入框，**打完字按回车**。

拆开看这一行做了三件事：

1. 把 `"请输入你的名字："` 显示出来
2. **停下来等你打字**
3. 你按回车后，把你输入的内容装进 `name` 盒子

## 📌 知识卡 2 · ⚠️ 最重要的一件事

**`input()` 拿回来的，永远是文字。**

哪怕你输入的是 `16`，它到手也是 `"16"` 这三个字符，而不是数字 16。

```python runnable 看看它到底是什么类型
age = input("你几岁了？")
print(age)
print(type(age))
```

`type()` 会告诉你一个东西是什么类型。看到 `<class 'str'>` 了吗？`str` 就是**文字**。

所以下面这段一定会报错：

```python runnable 这段会报错，跑一次看看报错长什么样
age = input("你几岁了？")
print(age + 1)
```

试试看！**故意跑出报错是好事** —— 派森酱会把它翻译成人话给你看。

## 📌 知识卡 3 · 类型转换：让文字变成数字

想让它能算数，就得**转换**一下：

```python runnable 加个 int() 就好了
age = int(input("你几岁了？"))
print(f"明年你就 {age + 1} 岁啦")
```

看 `int(input(...))` 这个套娃写法，从**里往外**读：

1. 里面的 `input()` 先跑，拿到文字 `"16"`
2. 外面的 `int()` 把它变成数字 `16`

三个转换工具，记住它们：

| 工具 | 作用 | 例子 |
|---|---|---|
| `int()` | 变整数 | `int("16")` → `16` |
| `float()` | 变小数 | `float("1.62")` → `1.62` |
| `str()` | 变文字 | `str(16)` → `"16"` |

```python runnable 三兄弟
print(int("16") + 1)
print(float("1.5") * 2)
print(str(16) + " 岁")
```

⚠️ `int()` 挑食：`int("3.5")` 会报错，因为 `"3.5"` 不是整数的样子。
要先 `float()` 再 `int()`。

## 📌 知识卡 4 · 一次问好几个问题
