## 📌 知识卡 1 · 你早就在用函数了

```python runnable 这些都是函数
print("你好")
len("星野樱")
int("16")
sum([1, 2, 3])
```

`print`、`len`、`int`、`sum` —— **全都是函数**，Python 内置写好的。

你从第一天起就在用它们，只是不知道它们叫这个名字。

今天开始，**你也能造自己的函数了**。

---

## 📌 知识卡 2 · `def` —— 造一个函数

```python runnable 你的第一个函数
def greet():
    print("欢迎来到派森学院！")
    print("我是派森酱，请多指教～")

greet()
```

拆开看：

```
def  greet ():
 ↑     ↑    ↑
关键字 名字  括号（暂时空着）
    ← 这一行结尾要有冒号
    ← 下面缩进的部分，就是这个函数的「身体」
```

最后那句 `greet()` 是**调用** —— 「执行一次这个函数」。

⚠️ 调用时**括号不能省**：

```python runnable 忘了括号会怎样
def greet():
    print("你好")

greet
greet()
```

第一句 `greet` 什么都没发生 —— 那只是「提到」这个函数，没有执行它。
**括号 = 执行**。

---

## 📌 知识卡 3 · 定义 ≠ 执行

```python runnable 定义的时候不会跑
print("① 开始")

def greet():
    print("③ 函数里面的话")

print("② 定义完了，但函数还没跑")
greet()
```

看输出的顺序 —— **`def` 那一段在被调用之前，一次都不会执行**。

`def` 只是「登记」：告诉 Python「有个叫 greet 的零件，内容是这些」。
真正执行要等到 `greet()`。

⚠️ 所以**定义必须写在调用前面**：

```python runnable 顺序反了会报错
greet()

def greet():
    print("你好")
```

`NameError` —— 调用的时候 Python 还不认识 greet。

> 🧠 习惯：**所有函数定义写在文件上半部分，主流程写在下面。**

---

## 📌 知识卡 4 · 一次定义，到处调用 ⭐

这才是函数真正的价值：

```python runnable 调用三次
def show_line():
    print("─" * 30)

show_line()
print("  角色档案")
show_line()
print("  姓名：星野樱")
show_line()
```

想把分隔线改成 `=`？**只改函数里那一行**，三处全变。

对比不用函数的写法 —— 你得改三个地方，而且很容易漏掉一个。

> 💡 **同一段代码写了第二遍的时候，就该考虑做成函数了。**

---

## 📌 知识卡 5 · 函数里可以写任何东西

循环、判断、别的函数调用，全都行：

```python runnable 函数里有循环
def show_stars(n):
    for i in range(n):
        print("★" * (i + 1))

show_stars(4)
```

（括号里那个 `n` 是**参数**，明天专门学 —— 今天先见个面。）

函数里调用别的函数也完全没问题：

```python runnable 函数套函数
def show_line():
    print("=" * 24)

def show_title():
    show_line()
    print("   派森学院 · 入学通知")
    show_line()

show_title()
```

`show_title` 用了 `show_line` —— **小零件拼成大零件**，这就是「拆分问题」的意思。

## 📌 知识卡 6 · 起名和文档

函数名的规矩跟变量一样：小写 + 下划线，**用动词开头**最好读：

| 好名字 | 不好的名字 |
|---|---|
| `show_line()` | `xian()` |
| `roll_dice()` | `a()` |
| `check_password()` | `func1()` |

函数第一行可以写一句说明，叫 **docstring**：

```python runnable 给函数写说明
def show_line():
    """打印一条分隔线，宽度 30。"""
    print("─" * 30)

show_line()
print(show_line.__doc__)
```

用三引号包起来。写给未来的自己看的 —— 一周后你会感谢现在的你。

## 🛠 今天的任务 · 战斗播报零件库

把重复的打印代码做成函数，组一套「战斗播报」：

| 要求 | 说明 |
|---|---|
| `show_line()` | 打印一条至少 20 个字符的分隔线 |
| `show_title()` | 打印带上下分隔线的标题（内部要调用 `show_line`） |
| `show_hero()` | 打印我方角色信息（至少 2 行） |
| `show_enemy()` | 打印敌方角色信息（至少 2 行） |
| `show_victory()` | 打印胜利画面（至少 2 行，可以用循环） |
| 每个函数都写 docstring | 三引号一句话说明 |
| 主流程按顺序调用它们 | 定义在上、调用在下 |
| `show_line()` 至少被调用 4 次 | 体现「一次定义、多次调用」 |

> 💡 判题会检查函数**真的被定义了**，而且**真的被调用了**。
> 光定义不调用是不算数的 😉
