## 🧩 复习卡 · 三个最容易忘的点

### 1. `input()` 拿回来的永远是文字

```python runnable 忘了转换会怎样
age = input("年龄：")
print(f"明年 {age} 岁")
```

上面这段**不会报错**，但也**不会加 1** —— 因为你根本没做加法。
要算数就必须转：

```python runnable 转了才能算
age = int(input("年龄："))
print(f"明年 {age + 1} 岁")
```

### 2. 方法不改原变量，要用 `=` 接住

```python runnable 又是这个坑
s = "fire"
s.upper()
print(s)
s = s.upper()
print(s)
```

### 3. f-string 的 `f` 别忘了

```python runnable 有 f 和没 f
n = 5
print("有 {n} 个")
print(f"有 {n} 个")
```

## 🛠 今天的作品 · RPG 开场白系统

做一个完整的开场流程，分三幕。

### 第一幕 · 标题画面

用**三引号**打印一个游戏标题框。随便设计，好看就行。

### 第二幕 · 角色创建

问玩家四个问题（**顺序很重要，测试会按这个顺序喂数据**）：

| 顺序 | 问什么 | 变量 | 要转换吗 |
|---|---|---|---|
| 1 | 名字 | `name` | 不用，但要 `.strip()` |
| 2 | 年龄 | `age` | `int()` |
| 3 | 属性英文 | `element` | 不用 |
| 4 | 幸运数字 | `lucky` | `int()` |

然后**算出**这些数值：

| 变量 | 公式 |
|---|---|
| `hp` | `age * 20 + lucky` |
| `mp` | `age * 10 + lucky * 2` |
| `rank` | `len(name)` |
| `title` | 属性的大写形式，用 `.upper()` |

### 第三幕 · 角色卡

打印一张完整的角色卡，必须包含：

- 名字、`title`（大写属性）、`rank` 阶
- HP 和 MP 的数值
- 一条用 `"★" * rank` 生成的星星线
- 一行用 `sep` 打印的状态栏
- 一句用 `\n` 换行的旁白

> 🎯 这一关有点长，但每一块你都做过。
