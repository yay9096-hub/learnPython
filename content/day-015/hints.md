## 提示 1 · 倒计时和乘法表

倒计时的关键是 `range` 的第三个参数：

```python
for i in range(5, 0, -1):
    print(i)
print("发射！🚀")
```

念一遍：「从 5 开始，到 0 之前停，每次减 1」。
所以是 5、4、3、2、1 —— **终点 0 不包含**。

⚠️ `print("发射！")` 要**顶格**写，不能缩进。
缩进了就变成「每数一个数发射一次」。

乘法表就更直接了：

```python
for i in range(1, 10):
    print(f"7 × {i} = {7 * i}")
```

`range(1, 10)` 给的是 1~9。想要到 9，终点就写 10。

## 提示 2 · 金字塔先想「第 i 行长什么样」

画 ASCII 图案的通用套路：**列个表，找规律**。

| 第 i 行 | 空格 | 星星 |
|---|---|---|
| 1 | 4 | 1 |
| 2 | 3 | 3 |
| 3 | 2 | 5 |
| 4 | 1 | 7 |
| 5 | 0 | 9 |

看出来了吗？

- 空格 = `5 - i`
- 星星 = `2 * i - 1`

## 提示 3 · 拼起来

Day 5 学过「文字 × 数字 = 重复」，Day 1 学过「文字 + 文字 = 拼接」，
今天两个一起用：

```python
for i in range(1, 6):
    print(" " * (5 - i) + "★" * (2 * i - 1))
```

拆开看 `i = 3` 那一行：

- `" " * (5 - 3)` → 两个空格
- `"★" * (2 * 3 - 1)` → 五个星星
- 加起来 → `"  ★★★★★"`

⚠️ 括号别省。`"★" * 2 * i - 1` 的算法完全不一样。
