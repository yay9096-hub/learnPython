> 「昨天的 `while` 是「**不知道要几次**，反正条件不成立就停」。

## 📌 知识卡 1 · `for` + `range` —— 重复固定次数

先看 `while` 版本有多啰嗦：

```python runnable while 版：三件套一个不能少
n = 0
while n < 5:
    print("★")
    n += 1
```

再看 `for` 版：

```python runnable for 版：两行搞定
for i in range(5):
    print("★")
```

**初始化、条件、递增全都不用自己写了**，`for` 帮你办好。

写法：

```
for  变量  in  range(次数) :
    要重复做的事
```

同样是**冒号 + 缩进**。

---

## 📌 知识卡 2 · 那个 `i` 是什么

`i` 是**循环变量**，它会自动从 0 开始，每转一圈加 1：

```python runnable 把 i 打印出来看看
for i in range(5):
    print(i)
```

⚠️ **注意它是从 0 开始，到 4 结束** —— `range(5)` 给的是 `0 1 2 3 4`，**总共 5 个数，但没有 5**。

这跟 Day 5 学的「Python 从 0 开始数」是同一件事。

想从 1 数到 5 怎么办？给 `range` 两个参数：

```python runnable range(起点, 终点)
for i in range(1, 6):
    print(i)
```

⚠️ **终点不包含**。想数到 5，就要写 `range(1, 6)`。
这一点很反直觉，但用几次就习惯了。

| 写法 | 得到 |
|---|---|
| `range(5)` | 0 1 2 3 4 |
| `range(1, 6)` | 1 2 3 4 5 |
| `range(2, 11, 2)` | 2 4 6 8 10（第三个是步长） |
| `range(5, 0, -1)` | 5 4 3 2 1（倒着数） |

```python runnable 倒计时
for i in range(3, 0, -1):
    print(i)
print("发射！🚀")
```

## 📌 知识卡 3 · 循环变量能拿来算

这才是 `for` 真正好用的地方 —— `i` 不只是计数，还能参与运算：

```python runnable 九九乘法表的第 7 行
for i in range(1, 10):
    print(f"7 × {i} = {7 * i}")
```

配合 Day 5 学的「文字 × 数字」，就能画图案了：

```python runnable 金字塔的秘密
for i in range(1, 6):
    print("★" * i)
```

第 1 行 1 颗星、第 2 行 2 颗……**行号正好就是星星的个数**。

看出套路了吗？画 ASCII 图案的关键就是：
**找出「第几行」和「这行长什么样」之间的关系。**

## 📌 知识卡 4 · 加上空格，让它居中

```python runnable 真·金字塔
for i in range(1, 6):
    print(" " * (5 - i) + "★" * i)
```

拆开看第 3 行（`i = 3`）：

- 空格：`5 - 3 = 2` 个
- 星星：`3` 个
- 拼起来：`"  ★★★"`

行号越大，空格越少、星星越多 —— 就斜出一个三角形。

```python runnable 对称金字塔（每行星星是奇数）
for i in range(1, 6):
    print(" " * (5 - i) + "★" * (2 * i - 1))
```

## 📌 知识卡 5 · `for` 也能直接遍历一串东西

`range` 只是其中一种用法。`for` 还能直接把一串东西**一个个拿出来**：

```python runnable 遍历一个列表
for name in ["星野樱", "月见琉璃", "天野灯"]:
    print(f"{name} 报到！")
```

```python runnable 遍历一段文字
for ch in "派森酱":
    print(ch)
```

这个用法第三章会大量使用，今天先混个眼熟。

## 📌 知识卡 6 · `for` 还是 `while`？

| 情况 | 用哪个 |
|---|---|
| **知道**要重复几次 | `for` |
| 要把一串东西一个个处理 | `for` |
| **不知道**几次，靠条件决定什么时候停 | `while` |
| 猜数字（猜对才停） | `while` |
| 打印 10 行图案 | `for` |

> 🧠 一句话：**数得清用 `for`，数不清用 `while`。**
