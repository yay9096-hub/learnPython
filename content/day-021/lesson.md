## 🧩 复习卡 · 四个最容易忘的点

### 1. 分支顺序：从严格到宽松

```python runnable 顺序错了就白写
score = 95

if score >= 60:
    print("及格")
elif score >= 90:
    print("优秀")
```

95 分只显示「及格」—— 因为先中了就跳过后面全部。

### 2. 归零在外，累加在内

```python runnable 归零写错地方
total = 0
for i in range(1, 6):
    total += i
print(total)
```

把 `total = 0` 挪进循环里试试，结果会变成 5。

### 3. 循环三件套

```python runnable 缺了第三件就是死循环
n = 0                # ① 循环前准备
while n < 3:         # ② 条件里用它
    print(n)
    n += 1           # ③ 循环里改它 ← 少了这句就停不下来
```

### 4. `input()` 拿回来永远是文字

```python runnable 又是这个坑
age = "16"
print(int(age) + 1)
```

## 🎮 今天的作品 · 文字冒险游戏

做一个分支剧情游戏。结构长这样：

```
        ┌─ 森林 ─┬─ 打怪 → 胜利结局
起点 ───┤        └─ 逃跑 → 平凡结局
        └─ 洞穴 ─┬─ 拿宝箱 → 宝藏结局
                 └─ 转身走 → 平凡结局
```

### 三幕结构

**第一幕 · 角色创建**
问名字，随机生成初始属性（HP、攻击力）。

**第二幕 · 分支冒险**
至少 **2 个选择点**，每个点至少 2 个选项。
用 `while` 让输入错误时能重问（不许一输错就崩）。

**第三幕 · 结局**
至少 **3 种不同结局**，根据过程中的选择和战斗结果决定。

### 硬性要求

| 要求 | 说明 |
|---|---|
| 问名字 | `input()`，存进 `name` |
| 随机属性 | `random.randint` 生成 HP 和攻击力 |
| 至少 2 个选择点 | 每个点用 `input()` 让玩家选 |
| 用 `while` 做输入校验 | 输入了无效选项要能重问 |
| 至少 3 种结局 | 用 `if / elif / else` 分出来 |
| 战斗环节用循环 | 回合制，跟 Day 20 一样 |
| 结局里报出统计 | 比如「你走了 N 步 / 打了 N 回合」 |
| 输出里有「结局」两个字 | 判题要认 |

> 💡 判题会走两条不同的路线（选 1-1 和选 2-1），
> **两条路都要能走到结局**，不能崩、不能卡住。
>
> 🎯 做完之后把它发给同学玩 —— 这是你的第一个「作品」，不是「作业」。
