## 📌 知识卡 1 · 手动统计：循环 + 累加器

Day 17 的累加器模式，遍历列表时一样用：

```python runnable 手动求和
hps = [340, 280, 310, 250, 420]

total = 0                    # ① 循环外归零
for hp in hps:
    total += hp              # ② 循环内累加

print(f"总血量：{total}")     # ③ 循环外使用
```

**归零在外，累加在内，使用在外** —— 老规矩。

## 📌 知识卡 2 · 但 Python 有现成的

上面那 4 行，Python 一行就够：

```python runnable sum 一行搞定
hps = [340, 280, 310, 250, 420]
print(sum(hps))
```

配套的还有两个：

```python runnable 三兄弟
hps = [340, 280, 310, 250, 420]

print(f"总和：{sum(hps)}")
print(f"最高：{max(hps)}")
print(f"最低：{min(hps)}")
```

| 函数 | 作用 |
|---|---|
| `sum(列表)` | 加起来（只能对数字用） |
| `max(列表)` | 最大的那个 |
| `min(列表)` | 最小的那个 |
| `len(列表)` | 有几个 |

> 🧠 那还学累加器干嘛？
> 因为 `sum()` 只会**加**。想「统计有几个 SSR」「算加权总分」「跳过某些项」，
> 还是得靠循环 —— 累加器是**万能**的，`sum()` 只是快捷方式。

## 📌 知识卡 3 · 平均值

Python 没有内置的 `avg()`，自己算：

```python runnable 平均血量
hps = [340, 280, 310, 250, 420]

avg = sum(hps) / len(hps)
print(avg)
print(round(avg, 1))
```

⚠️ `/` 的结果是小数（Day 3 学的），所以配 `round(..., 1)` 保留一位更好看。

⚠️ 还有个坑：**列表为空时会除以 0**。

```python runnable 空列表会崩
hps = []
print(sum(hps) / len(hps))
```

健壮的写法先检查一下：

```python runnable 安全的平均值
hps = []

if len(hps) > 0:
    print(sum(hps) / len(hps))
else:
    print("队伍是空的，算不了平均值")
```

## 📌 知识卡 4 · 两个列表配对：用编号对齐

名字和血量分开存在两个列表里，怎么对上号？**用同一个编号。**

```python runnable 名字和血量对齐
names = ["星野樱", "月见琉璃", "天野灯"]
hps = [340, 280, 310]

for i in range(len(names)):
    print(f"{names[i]} 的血量是 {hps[i]}")
```

`range(len(names))` 给出 `0 1 2`，正好是两个列表共用的编号。

> ⚠️ 前提是**两个列表一样长、顺序一致**。这种「平行列表」的做法能用，
> 但有点脆弱 —— 第 29 天学了字典之后会有更好的办法。

## 📌 知识卡 5 · 找出最强的是谁

`max(hps)` 只能告诉你**最高的数值**，不能告诉你**是谁**。想知道是谁，
用 Day 17 的「找最值」套路，同时记住名字：

```python runnable 找出最强的成员
names = ["星野樱", "月见琉璃", "天野灯"]
hps = [340, 280, 420]

best_name = ""
best_hp = 0

for i in range(len(names)):
    if hps[i] > best_hp:
        best_hp = hps[i]
        best_name = names[i]

print(f"最强的是 {best_name}，血量 {best_hp}")
```

关键在于**两个变量一起更新** —— 找到更大的血量时，把名字也换掉。

也可以用 `.index()` 走捷径：

```python runnable index 找位置
names = ["星野樱", "月见琉璃", "天野灯"]
hps = [340, 280, 420]

top = max(hps)
where = hps.index(top)
print(f"最强的是 {names[where]}，血量 {top}")
```

`.index(x)` 会告诉你 `x` 在列表里的**编号**。

## 📌 知识卡 6 · 条件统计

想「只统计血量超过 300 的人」？循环里加个 `if` 就行：

```python runnable 数一数有几个高血量成员
hps = [340, 280, 310, 250, 420]

strong = 0
for hp in hps:
    if hp > 300:
        strong += 1

print(f"血量超过 300 的有 {strong} 人")
```

**这就是 `sum()` 做不到、必须靠循环的场景。**
