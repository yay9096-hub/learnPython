## 提示 1 · 先把「全达标」那一条写出来

四个条件用 `and` 串成一句，长是长了点，但读起来跟中文一样：

```python
if age >= 15 and mp >= 50 and element in ["火", "水", "风"] and record != "y":
    print("🎓 恭喜！你被录取了")
```

念一遍：「年龄够 **而且** 魔力够 **而且** 属性合法 **而且** 没有黑历史」。

⚠️ `record != "y"` 的意思是「不等于 y」，也就是「没有黑历史」。

## 提示 2 · 说明原因，就是把条件反过来问一遍

录取那条不成立时，用 `elif` 一条条查是哪里出了问题：

```python
elif age < 15:
    print(f"❌ 拒绝：年龄不够，要满 15 岁（你 {age} 岁）")
elif mp < 50:
    print(f"❌ 拒绝：魔力不足，要 50 点以上（你只有 {mp}）")
```

注意条件是**反过来写**的：
录取要 `age >= 15`，那查问题时就问 `age < 15`。

## 提示 3 · 完整骨架

```python
if age >= 15 and mp >= 50 and element in ["火", "水", "风"] and record != "y":
    print("🎓 恭喜！你被录取了")
elif age < 15:
    print(f"❌ 拒绝：年龄不够（你 {age} 岁）")
elif mp < 50:
    print(f"❌ 拒绝：魔力不足（你只有 {mp}）")
elif element not in ["火", "水", "风"]:
    print(f"❌ 拒绝：属性必须是 火/水/风（你填了「{element}」）")
else:
    print("❌ 拒绝：有黑历史，本院概不收录")
```

最后的 `else` 不用写条件 —— 走到这里就只剩「有黑历史」一种可能了。
