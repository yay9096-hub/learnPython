## 📌 知识卡 1 · 变量 = 一个贴了标签的盒子

变量就是**给一个值起个名字**，之后想用它，喊名字就行。

```python runnable 造一个盒子，再打开它
name = "星野樱"
print(name)
```

读作：把 `"星野樱"` 这个值，**装进**一个叫 `name` 的盒子里。

⚠️ 注意 `print(name)` 里的 `name` **没有引号**。

- 有引号 → 显示 `name` 这四个字母本身
- 没引号 → 显示盒子里装的东西

试试把引号加回去，看看差别：

```python runnable 有引号和没引号，差别巨大
name = "星野樱"
print(name)
print("name")
```

---

## 📌 知识卡 2 · 盒子里可以装数字

不只是文字，数字也能装。数字**不用加引号**。

```python runnable 一个角色的属性
name = "星野樱"
level = 12
hp = 340
print(name)
print(level)
print(hp)
```

> 🧠 记住这个区别，明天会很重要：
> `"12"` 是**文字**（不能拿来算数），`12` 是**数字**（可以算数）。

---

## 📌 知识卡 3 · 盒子里的东西可以换

同一个盒子，后面可以装别的东西进去，**旧的会被顶掉**。

```python runnable 升级！
level = 12
print(level)

level = 13
print(level)
```

Python 是**从上往下**执行的，所以第一次 print 时它还是 12。

---

## 📌 知识卡 4 · f-string —— 把变量塞进句子里 ⭐

这是今天最有用的一招，以后天天用。

在引号**前面**加一个字母 `f`，然后在句子里用 `{}` 把变量括起来：

```python runnable f-string 登场
name = "星野樱"
level = 12
print(f"{name} 现在是 {level} 级")
```

对比一下没有 f-string 的写法有多难受：

```python runnable 不用 f-string 的痛苦
name = "星野樱"
level = 12
print(name + " 现在是 " + str(level) + " 级")
```

- 要自己数空格
- 数字还得用 `str()` 转成文字，不然会报错

所以 —— **以后一律用 f-string**，别为难自己 (๑•̀ㅂ•́)و

### 两个容易踩的坑

```python runnable f 忘了写会怎样
name = "星野樱"
print("我是{name}")
print(f"我是{name}")
```

第一行的 `{name}` 会被原样显示出来，因为没有 `f`，Python 不知道要替换。

---

## 📌 知识卡 5 · 变量起名的规矩

| 可以 | 不可以 |
|---|---|
| `name` `hp` `max_hp` `level2` | `2level`（不能数字开头） |
| 全小写 + 下划线（推荐） | `max hp`（不能有空格） |
| 英文 | `print` `str`（别抢 Python 的名字） |

⚠️ **大小写是区分的**：`name` 和 `Name` 是两个完全不同的盒子。
