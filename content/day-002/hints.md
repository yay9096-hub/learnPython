## 提示 1 · 先搞清楚 f-string 的样子

三个零件，缺一不可：

1. 引号**前面**的 `f`
2. 引号本身
3. 大括号 `{}` 里放变量名

```python
print(f"姓名：{name}")
```

## 提示 2 · 一行一个属性

面板有 4 行内容，所以要写 4 个 f-string 的 print：

```python
print(f"   姓名：{name}")
print(f"   等级：Lv.{level}")
# 剩下两行你来写
```

## 提示 3 · 大括号里只放变量名

```python
print(f"   生命：{hp} / {hp}")
```

`{}` 里面**只写变量名**，不要加引号。
`{hp}` 对，`{"hp"}` 错。

想在一行里放两个变量？写两对 `{}` 就行。
