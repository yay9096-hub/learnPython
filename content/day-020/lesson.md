## 📌 知识卡 1 · 战斗的本质是「状态在循环里被改变」

一场战斗就是：

1. 双方各有一个**状态**（血量）
2. 每一回合，状态**被改变**（扣血）
3. 直到某个状态**触发结束条件**（有人血量 <= 0）

翻译成代码：

```python runnable 最简单的战斗
hp_a = 100
hp_b = 100

while hp_a > 0 and hp_b > 0:
    hp_b -= 30
    hp_a -= 25
    print(f"A: {hp_a}  B: {hp_b}")

print("战斗结束")
```

看循环条件：`hp_a > 0 and hp_b > 0` —— **只要两个都还活着就继续**（Day 13 的 `and`）。

`hp_b -= 30` 是 `hp_b = hp_b - 30` 的简写（Day 14 学的 `+=` 的兄弟）。

> 🧠 **循环三件套**又出现了：
> ① 循环前设好血量 ② 条件里用血量 ③ 循环里扣血
> 少了第③步就是死循环。

## 📌 知识卡 2 · 加上回合数和随机伤害

```python runnable 有回合数的战斗
import random

hp_a = 200
hp_b = 200
turn = 0

while hp_a > 0 and hp_b > 0:
    turn += 1
    dmg = random.randint(20, 50)
    hp_b -= dmg
    print(f"第 {turn} 回合：A 造成 {dmg} 点伤害 → B 剩 {hp_b} HP")

    dmg = random.randint(20, 50)
    hp_a -= dmg
    print(f"第 {turn} 回合：B 造成 {dmg} 点伤害 → A 剩 {hp_a} HP")

print(f"战斗结束，共 {turn} 回合")
```

多跑几次，每场都不一样 ✨

## 📌 知识卡 3 · ⚠️ 一个逻辑漏洞

上面那段有个 bug：**A 已经把 B 打死了，B 还能反击一次。**

因为循环条件只在**每轮开头**检查，一轮里的两次攻击都会执行完。

修法：B 出手前先看看它还活着吗 ——

```python runnable 修好之后
import random

hp_a = 200
hp_b = 200
turn = 0

while hp_a > 0 and hp_b > 0:
    turn += 1

    hp_b -= random.randint(20, 50)
    print(f"第 {turn} 回合：A 出手 → B 剩 {hp_b} HP")

    if hp_b <= 0:
        break                       # B 倒下了，这一轮到此为止

    hp_a -= random.randint(20, 50)
    print(f"第 {turn} 回合：B 出手 → A 剩 {hp_a} HP")

print("战斗结束")
```

> 💡 这种「**多想一步，发现漏洞**」的能力，比记住语法重要得多。
> 写完程序之后问自己一句「有没有什么情况会出问题？」——
> 这就是从「会写代码」到「会写对代码」的分界线。

## 📌 知识卡 4 · 判断谁赢了

循环结束后，看谁的血量还大于 0：

```python runnable 分出胜负
hp_a = 0
hp_b = 45

if hp_a <= 0 and hp_b <= 0:
    print("🤝 同归于尽！")
elif hp_a > 0:
    print("🏆 A 获胜！")
else:
    print("🏆 B 获胜！")
```

⚠️ 「同归于尽」要放**最前面** —— 这是 Day 12 学的**分支顺序**：
最特殊的情况写最前面。

## 📌 知识卡 5 · 统计总伤害

Day 17 的累加器模式，这里再用一次：

```python runnable 统计总伤害
import random

total_a = 0                                # ① 循环外归零

for i in range(5):
    dmg = random.randint(20, 50)
    total_a += dmg                         # ② 循环内累加
    print(f"第 {i + 1} 击：{dmg}")

print(f"总伤害：{total_a}")                # ③ 循环外使用
```

## 🛠 今天的任务 · 回合制战斗模拟

| 要求 | 说明 |
|---|---|
| 两个角色，各有血量 | `hp_a`、`hp_b`，都设成 200 |
| 用 `while` 循环打到一方倒下 | 条件用 `and` |
| 每回合双方各出手一次 | 伤害用 `random.randint(20, 50)` |
| 每次出手都打印战况 | 谁打的、多少伤害、对方剩多少血 |
| 统计回合数 | 存进 `turn` |
| 统计双方总伤害 | 两个累加器 |
| 修掉「死了还能反击」的漏洞 | 用 `break` |
| 最后宣布胜负 | 输出里有「获胜」，平局时有「同归于尽」 |

> 💡 判题会把伤害固定住来检查回合数和统计，所以**逻辑必须真的对**。
> 固定伤害是每次 50，双方血量 200 —— 自己先算算该打几个回合 😉
