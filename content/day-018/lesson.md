## 📌 知识卡 1 · 外层管行，内层管列

```python runnable 3 行 4 列
for row in range(3):
    for col in range(4):
        print(f"({row},{col})", end=" ")
    print()
```

看输出，是不是一个 3×4 的网格？

执行顺序是这样的：

```
外层 row=0 → 内层 col 跑完 0,1,2,3 → 换行
外层 row=1 → 内层 col 又跑完 0,1,2,3 → 换行
外层 row=2 → 内层 col 再跑完 0,1,2,3 → 换行
```

> 🧠 **口诀：外层跑一圈，内层跑一整轮。**
> 总次数是**相乘**的：3 × 4 = 12 次。

---

## 📌 知识卡 2 · `end=""` —— 让内层不换行

这是画图案的关键技巧（Day 6 学过 `end`，今天派上大用场）：

```python runnable 对比一下有没有 end
print("=== 有 end 的版本 ===")
for row in range(3):
    for col in range(5):
        print("★", end="")
    print()

print("=== 没有 end 的版本 ===")
for row in range(3):
    for col in range(5):
        print("★")
```

- 内层用 `end=""` → 星星**横着排**
- 外层那个光秃秃的 `print()` → 一行画完了，**换行**

⚠️ 那个空的 `print()` 必须缩进在**外层**（4 格），不能在内层。
放错地方就每颗星星都换行了。

## 📌 知识卡 3 · 棋盘：内层用 if 判断该画什么

```python runnable 8×8 棋盘
for row in range(8):
    for col in range(8):
        if (row + col) % 2 == 0:
            print("⬛", end="")
        else:
            print("⬜", end="")
    print()
```

`(row + col) % 2` 是个很妙的技巧：
行列坐标相加，奇偶交替，正好画出棋盘格。

> 💡 这就是嵌套循环的通用套路：
> **外层决定在第几行，内层决定这一格画什么。**

## 📌 知识卡 4 · 九九乘法表

```python runnable 完整九九乘法表
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}×{i}={i * j}", end="\t")
    print()
```

注意内层的 `range(1, i + 1)` —— **内层的范围用到了外层的变量**。

- `i = 1` 时，内层只跑 1 次
- `i = 9` 时，内层跑 9 次

所以打印出来是个三角形，而不是方块。**这一招是画三角形图案的核心。**

## 📌 知识卡 5 · 菱形

菱形 = 上半个金字塔 + 下半个倒金字塔。两段循环拼起来：

```python runnable 菱形
n = 5

# 上半部分（含中间那行）
for i in range(1, n + 1):
    print(" " * (n - i) + "★" * (2 * i - 1))

# 下半部分
for i in range(n - 1, 0, -1):
    print(" " * (n - i) + "★" * (2 * i - 1))
```

下半部分就是把上半部分**倒着跑一遍**（`range` 的第三个参数用 `-1`），
而且要少一行（从 `n - 1` 开始），不然中间那行会重复。

## 📌 知识卡 6 · `break` 在嵌套循环里只跳一层

```python runnable break 只跳出内层
for row in range(3):
    for col in range(5):
        if col == 2:
            break
        print(f"({row},{col})", end=" ")
    print()
```

内层遇到 `break` 就停，但**外层照样进入下一圈**。

想跳出全部？常用做法是设一个标记变量，或者把这段代码放进函数里用 `return`
（函数第四章会学）。
