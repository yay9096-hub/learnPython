## 提示 1 · 卡在「不知道做什么」怎么办

这是最难的一步，每个程序员都经历过。

**别想「什么厉害」，想「我自己会用哪个」。**

三个最容易上手的方向：

| 方向 | 一句话 | 核心数据 |
|---|---|---|
| 收藏管理器 | 记录番剧 / 书 / 歌单，打分排序 | 一个列表，每项是一个对象 |
| 占卜 / 生成器 | 输入名字，生成运势卡片 + 魔法阵 | 几个列表 + turtle |
| 小游戏 | 猜谜 / 卡牌 / 文字冒险，带存档 | 一个类 + 一个 json 存档 |

**最省心的选择是「收藏管理器」** —— 它天然需要类、列表、字典、
文件存档、排序、图表，正好把毕业标准全覆盖了。

## 提示 2 · 先跑起来，再加功能

**第一步只写这些，然后立刻跑一次：**

```python
"""我的收藏管理器 —— 记录看过的番剧并打分。"""

SAVE_FILE = "我的收藏.json"
MAX_SCORE = 10


class Item:
    """一条收藏记录。"""

    def __init__(self, name, score=5):
        self.name = name
        self.score = score

    def __str__(self):
        return f"{self.name} {self.score}/10"


items = [Item("魔法少女小圆", 10), Item("孤独摇滚", 9)]
for it in items:
    print(it)
```

**跑通了？** 现在一次加一个功能，每加完跑一次：

1. 加 `stars()` 方法（把分数变成星星）
2. 加 `load_list` / `save_list`（存档）
3. 加 `find` / `top_rated`（查找和排序）
4. 加 `draw_chart`（画图）
5. 加 `try / except`（防崩）

**每一步都跑一次。** 出错了立刻知道是刚才那几行的问题。

## 提示 3 · 对着毕业标准一条条勾

写完之后，拿任务表逐条检查：

```
□ 文件开头三引号说明          → 第 1 行
□ 3 个全大写常量              → SAVE_FILE / MAX_SCORE / CHART_FILE
□ 6 个函数，每个有 docstring   → 数一数
□ 1 个类，__init__ + 2 方法    → Item 类
□ 类里有 __str__              → 有
□ 用到列表和字典              → items 列表、to_dict 返回字典
□ try / except（写明类型）     → load_list 里
□ 读或写文件                  → save_list / load_list
□ 循环 + 条件判断             → for + if
□ 产出图（turtle 或图表）      → draw_chart
□ 完整跑完不崩                → 跑一次
□ 命名都有意义                → 通读一遍
```

### 几个容易漏的

- **常量数不够**：文件名、上限、图片名，凑三个很容易
- **函数少于 6 个**：把「打印列表」「算统计」这些也拆成函数
- **类定义了没用**：主流程里要真的 `Item(...)` 造对象
- **忘了画图**：哪怕只画一张最简单的柱状图也行
