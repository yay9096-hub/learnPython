## 📌 复习卡 1 · 双层循环：一局 vs 多局

这是今天结构上唯一的新东西 —— **两层 `while` 嵌套**：

```python runnable 双层循环的骨架
games = 0

while True:                       # 外层：多局游戏
    games += 1
    print(f"=== 第 {games} 局开始 ===")

    tries = 0
    while tries < 3:              # 内层：一局里的多次猜测
        tries += 1
        print(f"  第 {tries} 次尝试")

    print(f"=== 第 {games} 局结束 ===")

    if games >= 2:                # 演示用：玩两局就停
        break
```

- **外层**管「玩第几局」
- **内层**管「这一局猜第几次」
- 每层各自有自己的计数器，互不干扰

## 📌 复习卡 2 · 用次数限制做循环条件

Day 14 的循环条件只有「没猜对」，今天再加一个「还有次数」：

```python runnable 限次猜测
answer = 42
guess = 0
tries = 0
max_tries = 3

while guess != answer and tries < max_tries:
    tries += 1
    guess = int(input(f"第 {tries}/{max_tries} 次，猜："))
    if guess > answer:
        print("太大了")
    elif guess < answer:
        print("太小了")

if guess == answer:
    print(f"🎉 猜对了！用了 {tries} 次")
else:
    print(f"💀 次数用完了，答案是 {answer}")
```

⚠️ 循环结束后**必须判断是怎么结束的** ——
是猜对了，还是次数用完了？两种情况的提示完全不同。

这个「循环结束后判断退出原因」的模式非常常用，记住它。

## 📌 复习卡 3 · 难度决定参数

```python runnable 难度选择
level = "2"

if level == "1":
    top, chances = 50, 10
elif level == "2":
    top, chances = 100, 7
else:
    top, chances = 500, 9

print(f"范围 1~{top}，你有 {chances} 次机会")
```

> 💡 `top, chances = 50, 10` 是一次给两个变量赋值的简写，很方便。
> （完整原理是「元组解包」，第三章会讲。）
