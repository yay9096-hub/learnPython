## 提示 1 · if 的三个零件

```python
if password == "sakura":
    print("欢迎")
```

对照检查：

1. `if` 后面是**条件**（一个「是不是」的问题）
2. 这一行**结尾有冒号 `:`**
3. 下一行**往右缩进 4 个空格**

⚠️ 判断相等要写**两个等号** `==`，一个等号是赋值，会报错。

## 提示 2 · else 要顶格对齐

```python
if password == "sakura":
    print("✨ 口令正确，欢迎进入结界")
else:
    print("⛔ 口令错误，拒绝入内")
```

注意 `else` 的位置 —— 它跟 `if` **左边对齐**，不缩进。
它下面那行才缩进。

写错的样子长这样（会报错）：

```python
if password == "sakura":
    print("欢迎")
    else:                    # ← 缩进了，错
        print("拒绝")
```

## 提示 3 · 第二段是一模一样的套路

魔力判断跟口令判断结构完全相同，只是条件换了：

```python
mp = int(input("报上你的魔力值："))

if mp >= 50:
    print(f"魔力 {mp} 点，足够施法！")
else:
    print(f"魔力只有 {mp} 点，不足以施法")
```

⚠️ `input()` 拿回来是文字，要 `int()` 转成数字才能跟 50 比大小 —— 这是 Day 4 学的。
