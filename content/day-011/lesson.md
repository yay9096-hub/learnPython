## 📌 知识卡 1 · `if` —— 如果……就……

```python runnable 血量判断
hp = 80

if hp > 0:
    print("你还活着！")
```

把 `hp` 改成 `0` 再跑一次 —— 那一行 `print` 就不执行了。

`if` 的写法有**三个零件**，一个都不能少：

```
if  条件 :
    要做的事
```

1. `if` 后面跟**条件**
2. 这一行**结尾必须有冒号 `:`**
3. 下面那行**必须往右缩进 4 个空格**

---

## 📌 知识卡 2 · ⚠️ 缩进就是「归谁管」

这是今天最容易出错的地方，请认真看这两段的区别：

```python runnable 缩进了：归 if 管
hp = 0

if hp > 0:
    print("你还活着！")
    print("继续战斗")
print("—— 游戏结束 ——")
```

前两个 `print` 缩进了，所以**归 `if` 管**，条件不成立就不执行。
最后一行顶格写，**不归 if 管**，无论如何都会执行。

Python 就是靠**行首的空格**判断「这段代码归谁管」的。
别的语言用大括号，Python 用缩进 —— 所以缩进在 Python 里不是排版，**是语法**。

> 💡 编辑器已经帮你做好了：写完带冒号的行，按回车会自动缩进。

## 📌 知识卡 3 · 比较：问一个「是不是」的问题

条件的本质是一个**「对还是不对」的问题**。

```python runnable 六个比较符号
print(10 > 3)
print(10 < 3)
print(10 >= 10)
print(10 == 10)
print(10 != 3)
```

结果只有两种：`True`（对）和 `False`（不对）。这是一种新的数据类型，叫**布尔值**。

| 符号 | 意思 |
|---|---|
| `>` `<` | 大于、小于 |
| `>=` `<=` | 大于等于、小于等于 |
| `==` | **等于**（两个等号！） |
| `!=` | 不等于 |

### ⚠️ `=` 和 `==` 千万别搞混

```python runnable 一个等号 vs 两个等号
hp = 100          # 一个等号：把 100 装进 hp
print(hp == 100)  # 两个等号：问「hp 是不是 100？」
```

- `=` 是**赋值**（装进去）
- `==` 是**比较**（问一句）

在 `if` 后面写成一个等号，Python 会直接报错。

文字也能比较，但要**完全一样**才算相等：

```python runnable 文字比较大小写敏感
print("fire" == "fire")
print("fire" == "Fire")
print("樱" == "樱")
```

## 📌 知识卡 4 · `else` —— 否则……

`if` 管「成立的情况」，`else` 管「其它所有情况」。

```python runnable 两条路，必走其一
password = "sakura"

if password == "sakura":
    print("✨ 结界打开，请进")
else:
    print("⛔ 口令错误，退下")
```

把 `password` 改成别的再跑一次。

规矩：

- `else` 要和 `if` **对齐顶格**（不能缩进）
- `else` 后面也要有**冒号**
- `else` 不带条件 —— 它的意思就是「上面那个没成立的话」

```python runnable 及格线
score = 55

if score >= 60:
    print("恭喜及格！")
else:
    print("差一点，再来一次")
```

## 📌 知识卡 5 · 条件里可以放任何算式

条件不一定是简单比较，可以先算再比：

```python runnable 边算边判断
atk = 88
defense = 100

if atk - defense > 0:
    print("能打穿防御！")
else:
    print("打不动，先升级吧")
```
