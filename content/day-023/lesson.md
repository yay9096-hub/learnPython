## 📌 知识卡 1 · 列表长什么样

**方括号 `[ ]`，里面用逗号隔开。**

```python runnable 一个变量装三个人
team = ["星野樱", "月见琉璃", "天野灯"]
print(team)
```

这一个 `team` 就装下了整支队伍。

其实你早就见过它了 —— Day 10 抽卡的 `random.choice([...])`、
Day 13 的 `element in ["火", "水", "风"]`，那些方括号就是列表。

列表里可以装任何东西，甚至混着装：

```python runnable 什么都能装
names = ["樱", "琉璃"]
hps = [340, 280]
mixed = ["樱", 16, 3.5, True]

print(names)
print(hps)
print(mixed)
```

空列表就是一对空的方括号：

```python runnable 先建个空的
team = []
print(team)
print(len(team))
```

## 📌 知识卡 2 · 用编号取出某一个

方括号后面写编号，就能取出其中一个：

```python runnable 点名
team = ["星野樱", "月见琉璃", "天野灯"]

print(team[0])
print(team[1])
print(team[2])
```

⚠️ **编号从 0 开始！** 这是今天最重要的一件事。

| 成员 | 星野樱 | 月见琉璃 | 天野灯 |
|---|---|---|---|
| 编号 | `0` | `1` | `2` |

3 个人的编号是 `0`、`1`、`2` —— **没有 `3`**。

```python runnable 越界会怎样（跑一下看看报错）
team = ["星野樱", "月见琉璃", "天野灯"]
print(team[3])
```

这个报错你在 Day 5 见过 —— `IndexError`。派森酱会翻译给你看 ✨

## 📌 知识卡 3 · 倒着数：负编号

想取最后一个，不用先算长度：

```python runnable 从后往前数
team = ["星野樱", "月见琉璃", "天野灯", "水城凛"]

print(team[-1])
print(team[-2])
```

| | 星野樱 | 月见琉璃 | 天野灯 | 水城凛 |
|---|---|---|---|---|
| 正着 | 0 | 1 | 2 | 3 |
| 倒着 | -4 | -3 | -2 | **-1** |

> 💡 `[-1]` 取最后一个，是 Python 里用得最多的技巧之一。

## 📌 知识卡 4 · `len()` —— 有几个

```python runnable 数人头
team = ["星野樱", "月见琉璃", "天野灯"]
print(len(team))
```

Day 5 你用 `len()` 数过字符串里有几个字，用法完全一样。

有了 `len()`，就能算出**最后一个的编号**：

```python runnable 长度和最大编号差 1
team = ["星野樱", "月见琉璃", "天野灯"]

print(f"一共 {len(team)} 人")
print(f"最后一个的编号是 {len(team) - 1}")
print(team[len(team) - 1])
```

**长度是 3，但最大编号是 2** —— 永远差 1。这就是「从 0 开始数」的代价。
（所以大家都直接用 `[-1]`，省心。）

## 📌 知识卡 5 · 改掉其中一个

列表是**可以改的**：

```python runnable 换人
team = ["星野樱", "月见琉璃", "天野灯"]
print(team)

team[1] = "夜刀神澪"
print(team)
```

`team[1] = ...` 就是「把 1 号位换成别人」。

⚠️ 对比一下字符串 —— 字符串**不能**这样改：

```python runnable 字符串改不了（会报错）
name = "樱"
name[0] = "月"
```

**列表能改，字符串不能改。** 这是两者最大的区别之一。

## 📌 知识卡 6 · `for` 遍历列表

Day 15 提过一句，今天正式用：

```python runnable 挨个点名
team = ["星野樱", "月见琉璃", "天野灯"]

for member in team:
    print(f"{member} 报到！")
```

念一遍：「**对于** team 里的**每一个** member，打印一句」。

比用编号取清爽多了。想同时要编号和内容，用 `enumerate`：

```python runnable 带编号的点名
team = ["星野樱", "月见琉璃", "天野灯"]

for i, member in enumerate(team):
    print(f"{i + 1} 号：{member}")
```
