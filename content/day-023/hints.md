## 提示 1 · 建列表和取成员

```python
team = ["星野樱", "月见琉璃", "天野灯", "水城凛", "夜刀神澪"]

print(f"当前队伍共 {len(team)} 人")
print(f"队长：{team[0]}")
print(f"替补：{team[-1]}")
```

三个要点：

- 方括号 `[ ]`，成员之间用**逗号**
- `team[0]` 是第一个（**从 0 开始数**）
- `team[-1]` 是最后一个（不用先算长度）

## 提示 2 · 带编号的点名

```python
for i, member in enumerate(team):
    print(f"{i + 1} 号：{member}")
```

`enumerate` 会同时给你**编号**和**内容**：

- 第一圈：`i = 0`，`member = "星野樱"`
- 第二圈：`i = 1`，`member = "月见琉璃"`

⚠️ 打印时写 `i + 1` —— 因为编号从 0 开始，但人类习惯从 1 开始数。

## 提示 3 · 换人

```python
print("⚡ 人员变动：月见琉璃转学了")
team[1] = "风见幽香"
```

`team[1] = ...` 就是「把 1 号位（也就是第 2 个人）换掉」。

⚠️ 别写成 `team = ["星野樱", "风见幽香", ...]` 重建一遍 ——
那样就没体现「列表可以改」这件事了。

完整结构长这样：

```python
team = [...]              # 建名单
print(人数、队长、替补)
点名一次                   # for 循环
team[1] = "新名字"         # 换人
点名第二次                 # 同样的 for 循环
```
