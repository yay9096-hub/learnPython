## 📌 知识卡 1 · `print` —— 让电脑说话

电脑本身是不会说话的，`print` 就是那个「说出来」的开关。

写法永远是这三步：**`print`** → **一对括号** → **括号里放要说的东西**。

```python runnable 让派森酱打个招呼
print("欢迎来到派森学院！")
```

点右上角的 **▶ 试一下**，看看下面会出现什么。

> 💡 这段代码是可以改的！把里面的字换成你想说的话，再点一次试试。

## 📌 知识卡 2 · 引号 = 「这是一段文字」

引号非常重要，它是在告诉 Python：**"里面这些是文字，别多想，照着显示就行"**。

对比一下这两行，只差一对引号，结果完全不同：

```python runnable 有引号 vs 没引号
print("5 + 3")
print(5 + 3)
```

- 有引号 → Python 当它是**一串字**，原样显示
- 没引号 → Python 当它是**算式**，先算出答案

引号有两种，`"双引号"` 和 `'单引号'`，**效果完全一样**，你喜欢哪个用哪个。
但是 —— 开头用哪种，结尾就得用哪种，不能一边一个。

⚠️ 必须是**英文半角**的引号。中文输入法打出来的 `“”` 长得很像，Python 不认识。

## 📌 知识卡 3 · 一个 `print` = 一行

想输出好几行？那就写好几个 `print`，一行一个，从上往下依次执行。

```python runnable 三行台词
print("我是派森酱")
print("紫发双马尾")
print("请多指教！")
```

Python 读代码就跟你读书一样：**从上到下，一行一行来**。

---

## 📌 知识卡 4 · 注释 —— 写给人看的话

`#` 后面的内容，Python 会**完全无视**。它是留给人看的备注。

```python runnable 井号后面 Python 全当没看见
# 这一整行都是注释，Python 会直接跳过
print("这一行才会执行")   # 写在代码后面也可以
```

为什么要写注释？

- 提醒自己「这段是干嘛的」，一周后回来看就不懵了
- 临时把某行代码 **关掉**（前面加个 `#`），想恢复再删掉

> 🧠 小技巧：调试的时候把可疑的那行前面加 `#`，跑一次看看还报不报错，
> 这是程序员最常用的排查手法之一。
