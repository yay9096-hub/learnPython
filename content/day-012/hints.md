## 提示 1 · 先把情况数清楚

别急着写代码，先在纸上列一遍一共有几种结果：

1. 属性不认识（不是火水风）→ 兜底
2. 两边一样 → 平局
3. 火 vs 风 → 优势
4. 风 vs 水 → 优势
5. 水 vs 火 → 优势
6. 剩下的（火vs水、风vs火、水vs风）→ 劣势

**6 种情况 = 1 个 if + 4 个 elif + 1 个 else。**

想清楚再写，比边写边想快得多。

## 提示 2 · 顺序很关键

把「平局」放在克制判断**前面**：

```python
if mine == enemy:
    print(f"🤝 都是{mine}属性，平局！")
elif mine == "火" and enemy == "风":
    print("🔥 火克风 —— 你占优势！")
```

如果平局放在后面，`火 vs 火` 会先被别的条件抓走，永远走不到平局。

> `and` 明天才正式学，今天先照着用：
> `A and B` 的意思是「A 成立**并且** B 也成立」。

## 提示 3 · 剩下的全是劣势

三种优势组合列完之后，其余的克制情况就**只剩劣势**了，
所以不用一条条写，交给 `else` 就行：

```python
elif mine == "水" and enemy == "火":
    print("💧 水克火 —— 你占优势！")
else:
    print("💀 属性被克，你处于劣势……")
```

那「不认识的属性」怎么办？把它挪到**最前面**先挡掉：

```python
if mine not in ["火", "水", "风"] or enemy not in ["火", "水", "风"]:
    print("❓ 我不认识这个属性")
elif mine == enemy:
    ...
```

（`not in` 和 `or` 明天会细讲，今天照抄即可。
 想不用它们也行 —— 那就把「不认识」放在最后的 `else` 里，
 但要先把三种劣势组合一条条列出来。）
