## 📌 知识卡 1 · 为什么不能一直写 if

先看一个**错误示范**，猜猜它会打印几行：

```python runnable 三个独立的 if
score = 95

if score >= 90:
    print("优秀")
if score >= 60:
    print("及格")
if score >= 0:
    print("有效成绩")
```

**三行全打印了！** 因为这是三个**互不相干**的判断，Python 每个都会试一遍。

可我们想要的是「优秀就够了，别再说及格了」—— 这就是 `elif`。

---

## 📌 知识卡 2 · `elif` —— 否则如果……

```python runnable 改成 elif 试试
score = 95

if score >= 90:
    print("优秀")
elif score >= 60:
    print("及格")
else:
    print("再努力一下")
```

只打印了一行 ✨

`elif` 是 **else if** 的缩写，意思是「**上面那些都没成立的话**，再看看这个」。

规则：

| 规则 | 说明 |
|---|---|
| 从上往下依次尝试 | 谁先成立就执行谁 |
| **中了一个，剩下全部跳过** | 这是 `elif` 和「一堆 if」最大的区别 |
| `elif` 可以写任意多个 | 两个、五个、十个都行 |
| `else` 最多一个，放最后 | 可以不写 |

## 📌 知识卡 3 · ⚠️ 顺序错了，结果就错

这是今天最重要的一个坑。看这段：

```python runnable 顺序写反了会怎样
score = 95

if score >= 60:
    print("及格")
elif score >= 90:
    print("优秀")
```

95 分居然只显示「及格」！

因为 Python 从上往下试：`95 >= 60` 先成立了，就直接执行并**跳过后面全部**，
根本没机会走到「优秀」那一条。

> 🧠 **口诀：条件要从「最严格」写到「最宽松」。**
> 成绩判定从高分往低分写，血量判定从满血往濒死写。

```python runnable 正确顺序：严格 → 宽松
score = 95

if score >= 90:
    print("优秀")
elif score >= 80:
    print("良好")
elif score >= 60:
    print("及格")
else:
    print("再努力一下")
```

把 `score` 改成 85、70、30 各跑一次，感受一下它怎么走的。

## 📌 知识卡 4 · 文字也能用 elif 分支

```python runnable 属性克制
element = "火"

if element == "火":
    print("火克风 🔥")
elif element == "风":
    print("风克水 🌪")
elif element == "水":
    print("水克火 💧")
else:
    print("未知属性")
```

`else` 在这里非常有用 —— 它兜住了**所有意料之外的输入**。
她输入「土」「asdf」「」都会落到 `else`，程序不会崩。

> 💡 好习惯：**只要有 `elif`，就配一个 `else` 兜底**。
> 想不出兜底该说什么？就说「我不认识这个」。

---

## 📌 知识卡 5 · 分支里可以再放分支

分支块里当然也能写 `if` —— 这叫**嵌套**。

```python runnable 嵌套判断
hp = 30
has_potion = True

if hp < 50:
    print("血量告急！")
    if has_potion:
        print("→ 喝下药水，回血 50")
    else:
        print("→ 没有药水，快跑！")
else:
    print("状态良好")
```

注意里层的 `if` 缩进了 **8 个空格**（4 + 4）。
每嵌套一层，就往右缩 4 格。

⚠️ 嵌套超过三层就很难读了 —— 真到那一步，通常说明该换个写法（明天会学到）。

## 🛠 今天的任务 · 属性克制判定

做一个**属性相克判定器**。规则是经典的三角克制：

```
火 🔥 克 风
风 🌪 克 水
水 💧 克 火
```

| 要求 | 说明 |
|---|---|
| 问玩家属性 | `input()`，存进 `mine` |
| 问对手属性 | `input()`，存进 `enemy` |
| 用 `elif` 做多分支 | 至少两个 `elif` |
| 我方克制对方 → 优势 | 输出里要有「优势」 |
| 对方克制我方 → 劣势 | 输出里要有「劣势」 |
| 属性相同 → 平局 | 输出里要有「平局」 |
| 输入了别的字 → 兜底 | 用 `else`，输出里要有「不认识」 |

> 💡 判题会跑四遍：火vs风（优势）、水vs风（劣势）、火vs火（平局）、土vs火（不认识）。
> **四条路都要走得通。**
