## 🧩 复习卡 · 四个最容易忘的

### 1. 列表方法不用接，字符串方法要接

```python runnable 又是这一对
bag = ["剑"]
bag.append("盾")          # 不用接
print(bag)

s = "fire"
s = s.upper()             # 必须接
print(s)
```

### 2. 字典的 `in` 查的是键

```python runnable in 查键不查值
role = {"name": "樱", "hp": 340}
print("name" in role)
print("樱" in role)
print("樱" in role.values())
```

### 3. 排序要把相关数据绑在一起

```python runnable 单独排一个列表会错位
names = ["樱", "琉璃", "灯"]
scores = [80, 95, 70]

pairs = list(zip(scores, names))
pairs.sort(reverse=True)
print(pairs)
```

### 4. 平均值要防除零

```python runnable 空列表会崩
scores = []
if len(scores) > 0:
    print(sum(scores) / len(scores))
else:
    print("没有数据")
```

## 🎯 今天的作品 · 班级成绩管理系统

数据是**列表套字典**（Day 31 的形状），每个学生三科成绩：

```python
students = [
    {"name": "星野樱",   "chinese": 88, "math": 92, "english": 79},
    {"name": "月见琉璃", "chinese": 95, "math": 78, "english": 91},
    {"name": "天野灯",   "chinese": 72, "math": 85, "english": 68},
    {"name": "水城凛",   "chinese": 90, "math": 99, "english": 94},
    {"name": "夜刀神澪", "chinese": 65, "math": 71, "english": 82},
    {"name": "风见幽香", "chinese": 84, "math": 88, "english": 87},
]
```

### 要做的六件事

| # | 功能 | 说明 |
|---|---|---|
| 1 | **算总分** | 给每个人加一个 `total` 字段（三科之和） |
| 2 | **成绩单** | 逐行显示 姓名 / 三科 / 总分 |
| 3 | **单科统计** | 每一科的最高分、最低分、平均分（保留 1 位） |
| 4 | **排行榜** | 按总分从高到低排序并显示名次 |
| 5 | **等第统计** | 按总分分档：≥270 优秀 / ≥240 良好 / ≥210 及格 / 其余待努力，报出各档人数 |
| 6 | **查询** | 问一个名字，显示他的完整成绩和名次；查不到提示「查无此人」 |

### 硬性要求

- 全部靠循环生成，`print` 不超过 20 个
- 排序用 `key=lambda`
- 至少用一次 `zip()` 或 `.items()`
- 查询前要检查存在性
