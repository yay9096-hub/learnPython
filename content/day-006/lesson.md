## 📌 知识卡 1 · `\n` —— 藏在字符串里的换行

`\n` 是一个**特殊记号**，Python 看到它就换行。

```python runnable 一个 print，两行输出
print("派森酱：\n你终于来了。")
```

注意是**反斜杠** `\`（键盘上回车键上方那个），不是 `/`。

```python runnable 一口气打四行
print("第一章\n\n魔法学院\n入学第一天")
```

写两个 `\n` 就是空一行。

---

## 📌 知识卡 2 · `\t` 和 `\`

```python runnable 对齐用的制表符
print("姓名\t等级\tHP")
print("星野樱\t12\t340")
```

`\t` 会跳到下一个对齐位，做小表格很方便。

那如果我就是想显示一个反斜杠呢？**写两个**：

```python runnable 想显示反斜杠就写两个
print("这是一个反斜杠：\\")
print("(๑•̀ㅂ•́)و")
```

| 记号 | 效果 |
|---|---|
| `\n` | 换行 |
| `\t` | 制表符（对齐） |
| `\` | 一个反斜杠 |
| `\"` | 一个双引号（当你的字符串本身用双引号包着时） |

```python runnable 引号里还想放引号
print("她说：\"我不会放弃的。\"")
```

## 📌 知识卡 3 · 三引号 —— 所见即所得 ⭐

`\n` 写多了眼睛疼。用**三个引号**包起来，怎么排版就怎么输出：

```python runnable 三引号大法
print("""
╔══════════════════════════╗
║  派森酱                  ║
║  「你终于来了。」        ║
╚══════════════════════════╝
""")
```

这是做 ASCII 艺术、大段台词的最佳工具。**里面的换行、空格全部原样保留。**

三引号也可以装进变量：

```python runnable 存起来反复用
logo = """
  ✦ 派森学院 ✦
"""
print(logo)
print(logo)
```

> 🧠 三引号还有个用法：写多行注释。
> 一段被三引号包住又没赋值给谁的文字，等于什么都没做，常拿来当说明。

## 📌 知识卡 4 · `print` 的两个隐藏参数

`print` 其实可以一次打印好几个东西，用逗号隔开：

```python runnable 逗号分隔，自动加空格
print("等级", 12, "级")
```

Python 默认用**空格**把它们粘起来。想换成别的？用 `sep`：

```python runnable sep 换个分隔符
print("星野樱", "12", "340", sep=" | ")
print("2026", "09", "01", sep="-")
```

还有 `end`，控制这一行**结尾**放什么（默认是换行）：

```python runnable end 让两个 print 挤在一行
print("加载中", end="")
print("...完成！")
```

```python runnable 做一条进度条
print("[", end="")
print("=" * 20, end="")
print("] 100%")
```
