## 吉祥物设定

**派森酱（Pyson-chan）** —— 紫发双马尾的 AI 助手，你的编程搭档。

- 全程用 SVG 绘制，无外部图片依赖，可换表情
- 表情态：`normal` / `happy` / `thinking` / `worried` / `excited` / `wink`
- 出现位置：首页、每日页顶部、运行结果反馈、报错翻译、提示卡

### 话术基调

| 场景 | 文案示例 |
|---|---|
| 打开新的一天 | "今天要解锁的技能是——！(๑•̀ㅂ•́)و✧" |
| 运行成功 | "叮！代码跑起来了～ 派森酱看到结果了！" |
| 报错 | "呜哇，程序卡住了…… (；´д｀) 别慌，我来翻译一下他在说什么：" |
| 任务全过 | "★ 任务完成 ★ 今天的你，又变强了一点点！" |
| 想看提示 | "要不要……派森酱悄悄告诉你一点点？(◍•ᴗ•◍)" |
| 连续打卡 | "连续第 9 天了！这个坚持度已经是 SSR 级别了！" |

> 原则：**卡通、鼓励、不油腻**。绝不说"你答错了"，只说"再看看这里？"

## 10 天课程主线（阶段 1 · 会说话）

全程围绕一个"魔法学院入学"的二次元设定串起来：

| Day | 知识点 | 项目 |
|---|---|---|
| 1 | `print` / 注释 / 字符串 | 二次元角色出场卡 |
| 2 | 变量 / f-string | 角色属性面板 |
| 3 | 数字类型 / 运算符 | 伤害计算器 |
| 4 | 类型转换 / `input` | 入学登记处（生成学生证） |
| 5 | 字符串方法 / `len` | 中二称号生成器 |
| 6 | 转义字符 / 多行字符串 / `print` 参数 | 剧情对话框 |
| 7 | **复习作品日** | RPG 开场白系统（综合 D1–6） |

### 实测中修掉的 3 个 bug

1. **回车提交失效** —— 表单的隐式提交在某些环境不触发，改成显式接 `onKeyDown`。
   她一定会按回车，这个必须稳。
2. **误报死循环** —— 程序停下来等 `input()` 时，8 秒的「是不是循环停不下来」警告会误弹。
   现在等输入不计时。
3. **幽灵超时提示** —— 被销毁的 Pyodide worker 的 90 秒启动超时定时器还在跑，
   90 秒后会往界面上扔一条假的「加载超时」。销毁时一并清掉。

### 刻意留下的已知限制

| 限制 | 说明 |
|---|---|
| 只带了 Pyodide 核心（13MB） | 没打包 numpy/matplotlib 的 wheel，第七章要画图表时再加 |
| `turtle` 是自写的 Canvas 子集 | 常用的十几个命令都有，`ontimer` / 事件绑定这类没做 |
| 没有变量可视化（Python Tutor 式单步） | 排在第二章讲循环之前做，那时候最需要它 |
| 移动端只能看，不能写 | 有意为之，手机上敲代码会毁掉第一印象 |
