# 03 · 课程大纲

约 **70 天**，每周 6 天新课 + 1 天复习作品日，每天 25~40 分钟。

## 一、七个阶段

| 阶段 | 天数 | 知识点 | 代表项目 |
|---|---|---|---|
| **1 · 会说话** | D1–10 | `print` / 变量 / 数据类型 / `input` / 运算符 / f-string / 类型转换 | 自我介绍卡片、BMI 计算器、单位换算、随机抽签器 |
| **2 · 会判断和重复** | D11–22 | `if-elif-else` / `while` / `for` / `range` / `break` `continue` / 布尔逻辑 | **猜数字**、九九乘法表、ASCII 图案、石头剪刀布、成绩等级判定 |
| **3 · 会管理数据** | D23–34 | `list` / `dict` / `tuple` / `set` / 字符串方法 / 切片 / 嵌套结构 | 单词本、歌词词频统计、班级成绩分析、通讯录 |
| **4 · 会拆分问题** | D35–44 | 函数 / 参数 / 返回值 / 默认值 / 作用域 / `import` / 自定义模块 | 计算器、随机密码生成器、番茄钟、**猜数字重构版** |
| **5 · 会和外界打交道** | D45–54 | 文件读写 / `with` / 异常处理 / `datetime` / `json` / 路径 | 日记本、记账本、错题本、CSV 成绩单 |
| **6 · 会造东西** | D55–63 | 类 / 对象 / 属性 / 方法 / `__init__` / 继承 / 特殊方法 | 图书管理系统、宠物养成、卡牌对战游戏 |
| **7 · 会做出好看的** | D64–70 | `matplotlib` / `turtle` / 正则 / 常用标准库 | 数据图表、turtle 绘画、文字版贪吃蛇 / 五子棋 |

## 二、编排上的两条硬原则

### 1. 每个项目的输出必须"看得见"
打印图案、画图、有交互的对话——这些是项目。
纯算法题（"求 100 以内所有质数"）留给日常练习题，**不要当项目**。
高中生的动力来自"我做出了一个东西"，不是"我的答案是对的"。

### 2. 同一个项目滚回来重做
- Day 11：用 `while` 写猜数字
- Day 44：用函数重构一遍，代码短了一半
- Day 58：加个 `Player` 类记录战绩和历史

她会**亲眼看到自己进步了**。这是整个课程里最强的正反馈，比任何徽章都有效。

## 三、每周第 7 天：复习作品日

不教新知识点，做三件事：

1. **回顾错题本** —— 这周提示用得最多的 2 个知识点，重做一次
2. **一个稍大的周末作品** —— 把这周所有知识点串起来的综合项目
3. **作品陈列** —— 把这周的作品卡加进陈列馆

## 四、内容文件结构

内容和代码彻底分开，以后加课 / 改课不用碰程序：

```
content/
  day-001/
    meta.json      # 标题、知识点列表、前置依赖、预计时长、难度
    lesson.md      # 讲解 + 知识卡（可运行片段用特殊代码块标记）
    starter.py     # 带 TODO 的初始代码
    solution.py    # 参考答案
    tests.py       # 判题用例
    hints.md       # 三级提示
    exercises.md   # 预测题 / 修 bug 题 / 补全题
  day-002/
    ...
```

### meta.json 示例

```json
{
  "day": 12,
  "title": "猜数字游戏",
  "hook": "今天你会做出一个能和你对话的游戏",
  "stage": 2,
  "concepts": ["while循环", "比较运算符", "break"],
  "requires": ["input", "if-else", "类型转换"],
  "estimated_minutes": 35,
  "needs_stdin": true
}
```

### lesson.md 里的可运行知识卡

用带标记的代码块，前端渲染成"知识卡 + [▶ 试一下] 按钮"：

    ```python runnable
    count = 0
    while count < 3:
        print("第", count, "次")
        count = count + 1
    ```

## 五、内容量估算

70 天 × (讲解 + 项目 + 3 级提示 + 判题用例 + 4 道练习) 是实打实的工作量。
**这是整个项目最大的风险，不是技术。** 见 [05-待决策与风险](05-待决策与风险.md)。
