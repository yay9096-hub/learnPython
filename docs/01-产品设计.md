# 01 · 产品设计

## 一、三个决定成败的判断

### 1. 菜鸟教程只能偷"知识点清单"，不能偷它的结构

[菜鸟教程 Python3](https://www.runoob.com/python3/python3-tutorial.html) 是**查阅型文档**——写给已经会编程的人快速查语法用的。
一个零基础高中生打开"Python3 数据类型"那一页，看到六种类型一次性铺开、还带着 `complex`、`frozenset`，第一反应是关掉。

**正确用法**：把它当作**知识点索引**（保证不漏知识点），然后按"每天只教 2~3 个点、每个点立刻有产出"重新编排。

> 内容建议自己重写而不是整站扒下来。一是版权干净，二是重写的过程会自然地把语言降到高中生能懂的水平。

### 2. 报错信息是零基础最大的劝退点 —— 做"中文报错翻译器"

`IndentationError: unexpected indent`、`TypeError: can only concatenate str (not "int") to str`
这些对她就是天书，而且**几乎所有现有网站都没解决这个问题**。

自己做本地站，完全可以把最常见的 30 条 Traceback 做成映射表。出错时显示：

```
😅 第 7 行：你想把文字和数字直接粘在一起
   Python 不允许 "我今年" + 18 这样写，
   得先把数字变成文字： "我今年" + str(18)
   👉 相关知识点：Day 3 · 类型转换
```

**这一个功能带来的坚持率，比任何游戏化徽章都高。** 属于本项目的杀手锏功能，优先级最高。

### 3. 练习类型不能只有"写一个完整程序"

每天都从空白文件写起，第 5 天就会崩溃。教学上成熟的做法是 **PRIMM 阶梯**
（Predict 预测 → Run 运行 → Investigate 探究 → Modify 修改 → Make 创作），
一天之内混用四种题型：

| 类型 | 例子 | 作用 |
|---|---|---|
| **预测** | "运行前先猜：这段会打印什么？" | 建立心里的执行模型 |
| **修 bug** | 给一段能跑但结果错的代码 | 学读报错、学调试 |
| **补全** | starter 里留 `# TODO` | 降低起步门槛 |
| **创作** | 当天的小项目 | 成就感来源 |

**一天的节奏**：预测 1 题 → 补全 2 题 → 修 bug 1 题 → 做项目。
这样即使项目做失败了，前面三种也已经给了正反馈。

## 二、现有学习网站调研

| 站点 | 它的核心做法 | 抄什么 / 避什么 |
|---|---|---|
| **Codecademy** | 左讲解 / 中编辑器 / 右终端三栏，每步一个 checkpoint，即时校验 | ✅ 三栏布局是这类产品的事实标准，直接抄<br>❌ 步子切得太碎，全程被牵着走，学完不会独立写程序 |
| **freeCodeCamp** | 测试驱动，每题列出测试清单，通过就打勾 | ✅ "任务清单打勾"的反馈形式非常上瘾，必抄 |
| **Replit 100 Days of Code** | 100 天日历式，每天短视频 + 小项目，浏览器 IDE | ✅ 跟本项目的设想几乎一样，"每日解锁"的仪式感是核心 |
| **CS50P（哈佛）** | 严谨的 problem set + 自动评分（check50） | ✅ 判题要多维度（输出 / 返回值 / 代码结构）<br>❌ 难度对高中生偏高，别照搬题目 |
| **Python Tutor** | 单步执行，实时画出变量、内存、调用栈 | ✅ **强烈建议内嵌或自己实现**。"变量到底是什么""循环怎么转的"，讲十遍不如看一遍动画 |
| **SoloLearn / Mimo** | streak 连击、XP、徽章 | ✅ 连续打卡日历热力图（像 GitHub 贡献图）<br>❌ 别搞排行榜，家里就一个人，比无可比 |
| **Advent of Code** | 每天 0 点解锁一道题 | ✅ 解锁的仪式感<br>❌ 但**别锁死**——她想连做三天要允许 |
| **Khan Academy（JS 课程）** | 改一行代码，右边预览立刻变 | ✅ **读到的每一句话都能立刻验证**，这是最有效的设计 |
| **菜鸟教程** | 知识点全 + 在线运行 | ✅ 知识点大纲<br>❌ 无路径、无反馈、无产出 |

### 行业共识（这几条所有好产品都做到了）

1. **摩擦要小** —— 不装环境，打开网页就能写
2. **反馈要快** —— 写 5 行就能跑出结果
3. **产出要看得见** —— 尤其对高中生：她要能把做出来的东西给爸爸看
